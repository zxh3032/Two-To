## 一、设计目标

登录注册是用户进入 Two-To 的第一步。它既要完成账号验证，也要建立 Two-To 的产品气质：温暖、可信、有陪伴感。页面不做常见的“居中白色表单卡片”，而是用一个带互动的小动物品牌区，让用户一进入产品就感知到 Two-To 与宠物陪伴、双向适配相关。

本期 UI 设计范围包括：登录页、邮箱注册页、完善基础资料页、找回密码页、账号与安全页，以及相关弹窗/抽屉。

## 二、整体视觉方向

### 2.1 关键词

- 温暖：延续当前 Two-To 的奶白、暖黄、桃粉色基调。
- 可信：表单区域清晰克制，错误提示明确，不用夸张装饰干扰操作。
- 陪伴：登录页左侧小动物会根据用户操作做出回应。
- 轻量建档：完善基础资料页像一次轻松的偏好选择，而不是严肃问卷。

### 2.2 色彩建议

- 奶白背景：`#fff8ef`
- 面板底色：`#fffdf8`
- 主按钮暖黄：`#f59e0b`
- 桃粉强调：`#e85d93`
- 薄荷绿状态：`#2f9e78`
- 文字深棕：`#3a2418`
- 边框浅杏：`#f1d4b7`

### 2.3 形状语言

- 表单控件使用 8px 圆角。
- 动物插画可更圆润，但不让表单控件变成过度可爱风。
- 左侧插画区域允许更有表现力，右侧表单区域保持安静。

## 三、登录页核心创意

### 3.1 五只小动物陪伴舞台

登录页左侧品牌区设计为一个“五只小动物陪伴舞台”。小动物不是静态插画，而是会根据用户鼠标和表单输入状态做出轻量反馈。

五只小动物：

- 白色博美：体型小，毛发蓬松，表情灵动，站在前排偏左。
- 棕色泰迪：卷毛、圆脸，动作活泼，站在前排偏右。
- 黑色德文猫：大耳朵、细长脸、机灵感，站在后排较高位置。
- 黑白美短起司：圆脸、黑白花纹，站在中排。
- 白色缅因猫：体型最大、毛发厚，姿态沉稳，作为后排视觉重心。

设计风格：

- 使用卡通化形象，不追求写实。
- 每只动物只保留容易识别的品种特征：毛色、耳形、脸型、体型、花纹。
- 不使用真实照片，避免风格不统一和版权风险。
- 可采用 SVG 或 CSS 分层绘制，方便控制眼睛、头部、脖子、耳朵和身体动作。

### 3.2 动效状态

#### 默认状态

- 五只小动物自然站位，整体像在等用户进入 Two-To。
- 眼睛轻微跟随鼠标移动。
- 可加入低频眨眼、耳朵轻动、尾巴轻摆。
- 动效幅度要小，不能让用户感觉表单旁边一直在晃。

#### 鼠标移动状态

- 小动物眼睛跟随鼠标方向移动。
- 头部可以有 1-3 度轻微转向。
- 不需要每只动物完全同步，建议有轻微延迟，让它们像各自有反应。

#### 输入账号状态

- 当手机号、邮箱、图片验证码、短信验证码或邮箱验证码输入框聚焦时，小动物向表单方向看。
- 前排小狗可以轻微抬头，猫咪可伸脖子观察。
- 动作语义是“好奇地看你填写”，不是窥探隐私。

#### 输入密码状态

- 当密码输入框聚焦且密码处于隐藏状态时，小动物仍然看向输入框，但眼神更收敛。
- 当用户点击“显示密码”时，小动物集体背过头、闭眼或用爪子遮住眼睛。
- 当用户再次隐藏密码时，小动物恢复正常观察状态。

#### 表单成功状态

- 登录成功、验证码校验通过、注册完成时，小动物做轻微庆祝动作。
- 动作建议：眨眼、抬爪、尾巴轻摆，不做烟花或夸张弹跳。

#### 表单错误状态

- 输入错误时，小动物轻微疑惑或歪头。
- 错误动效不应嘲讽用户，也不应过于明显。
- 错误提示仍以表单文本为主，小动物只是辅助反馈。

#### 降级状态

- 用户开启系统“减少动态效果”时，关闭头部、脖子、尾巴等位移动画，仅保留静态插画。
- 移动端首期可简化为静态或低频眨眼，不强制实现完整鼠标跟随。
- 低性能设备上如果出现卡顿，优先保证表单输入流畅。

### 3.3 左侧区域布局

桌面端：

```text
┌────────────────────────────┬──────────────────────┐
│ Two-To Logo                │ 登录/注册表单         │
│ 标题：从了解彼此开始        │ 手机号登录 / 邮箱登录 │
│ 副文案                      │ 表单字段              │
│                            │ 主按钮                │
│ 五只小动物陪伴舞台          │ 辅助入口              │
└────────────────────────────┴──────────────────────┘
```

左侧品牌区建议占页面宽度 52%-56%，右侧表单区占 44%-48%。

左侧文案：

- 标题：从了解彼此开始
- 副文案：登录后保存测评结果、宠物档案和长期照料记录。
- 路径标签：认识自己 / 认识宠物 / 建立档案 / 长期照料

移动端：

```text
┌────────────────────┐
│ Two-To Logo         │
│ 标题与简短文案       │
│ 小动物横向缩略舞台   │
│ 登录/注册表单        │
└────────────────────┘
```

移动端小动物舞台高度控制在 120-160px，不抢占表单首屏空间。

## 四、页面级交互设计

### 4.1 登录页

**信息结构**

- 左侧：品牌区 + 五只小动物陪伴舞台。
- 右侧：登录表单。
- 默认 Tab：手机号验证码登录。
- 次级 Tab：邮箱密码登录。
- 辅助入口：邮箱注册、忘记密码。

**手机号登录**

- 字段：手机号、图片验证码、短信验证码。
- 手机号固定中国大陆 `+86`。
- “获取验证码”按钮在手机号格式正确、图片验证码通过后可用。
- 获取验证码后进入 60 秒倒计时。
- 短信验证码通过后：
  - 已有账号：登录成功。
  - 新手机号：进入完善基础资料页。

**邮箱登录**

- 字段：邮箱、密码。
- 连续失败达到阈值后，展示图片验证码。
- 登录成功后进入首页或原目标页面。

**错误状态**

- 错误提示展示在表单字段下方。
- 不使用全局弹窗承载普通错误。
- 小动物可以轻微歪头，但错误信息必须由文字说明清楚。

### 4.2 邮箱注册页

**信息结构**

- 标题：创建 Two-To 账号
- 副文案：用邮箱保存你的测评结果和宠物档案。
- 字段：邮箱、密码、确认密码、图片验证码、邮箱验证码。
- 主按钮：下一步。
- 辅助入口：已有账号？去登录。

**交互**

- 邮箱格式正确、图片验证码通过后，邮箱验证码按钮可用。
- 邮箱验证码通过后进入完善基础资料页。
- 邮箱已注册时提示“该邮箱已注册，可直接登录或找回密码”。

### 4.3 完善基础资料页

**信息结构**

- 页面标题：先认识一下你
- 副文案：这些信息会用于推荐更适合你的宠物内容，之后可以修改。
- Step 1：基础信息，必填。
- Step 2：偏好信息，选填。

**Step 1 必填**

- 昵称。
- 养宠阶段。
- 感兴趣宠物类型。

**Step 2 选填**

- 养宠经验。
- 每日可陪伴时间。
- 居住情况。
- 养宠限制。

**交互**

- 单选项使用选项卡片。
- 多选项使用标签按钮。
- Step 2 提供“跳过，稍后再填”。
- 主按钮文案：完成并进入 Two-To。

### 4.4 找回密码页

**信息结构**

- 三步流程：验证账号 -> 输入验证码 -> 设置新密码。

**Step 1**

- 选择邮箱或手机号。
- 输入邮箱或手机号。
- 完成图片验证码。
- 发送 6 位验证码。

**Step 2**

- 输入 6 位验证码。
- 展示重新发送倒计时。

**Step 3**

- 新密码。
- 确认新密码。
- 主按钮：重置密码。

**成功态**

- 标题：密码已重置
- 文案：请使用新密码重新登录。
- 按钮：返回登录。

### 4.5 账号与安全页

**信息结构**

- 基础资料：昵称。
- 登录方式：邮箱、手机号。
- 密码安全：修改密码。
- 登录设备：当前设备、其他设备。

**设备卡片信息**

- 设备名称，例如 `Chrome · macOS`。
- 最近活跃时间。
- IP 摘要。
- 当前设备标签。

**危险操作**

- 解绑邮箱/手机号：二次确认 + 当前密码。
- 退出全部设备：二次确认 + 当前密码。
- 踢出单设备：二次确认。

## 五、通用状态文案

- 网络错误：网络异常，请稍后重试。
- 验证码发送失败：验证码发送失败，请稍后重试。
- 频繁发送：发送过于频繁，请 42 秒后再试。
- 登录过期：登录已过期，请重新登录。
- 设备失效：当前设备登录已失效，请重新登录。
- 密码错误：账号或密码不正确。
- 邮箱已注册：该邮箱已注册，可直接登录或找回密码。

## 六、实现边界

- 首期优先保证表单体验、强登录、验证码和账号安全链路可用。
- 五只小动物动效作为登录页体验亮点，但必须支持降级。
- 小动物插画建议使用 SVG/CSS 分层实现，避免引入大体积 GIF。
- 动效应尊重 `prefers-reduced-motion`。
- 移动端可先实现简化版互动，桌面端实现完整鼠标跟随和密码明文回避动作。
